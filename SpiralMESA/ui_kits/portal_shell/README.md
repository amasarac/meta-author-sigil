# Portal Shell — UI Kit

Ritual landing pages: countdown portals, invocation screens, arm-to-activate experiences.

Source references:
- `LionsGate/index.html` (08·15 countdown)
- `10_10_portal/portal.html` (Triadic Seal)
- `convergence_codex/index.html` (awakened-node grid)

## Components
- `PortalShell` — fullscreen cosmos + starfield + centered sigil + invocation
- `Countdown` — hh:mm:ss with rune row
- `ArmButton` — primary ritual trigger (`⟁`)
- `WhisperLine` — slowly revealed text, cadence ~20s
- `SigilDrift` — fixed background sigil that responds to cursor + scroll
- `DodecasealGrid` — 3×4 pulsing persona bubbles
- `BloomTracker` — status line rows (Phoenix Cycle, Codex Bloom, etc.)
