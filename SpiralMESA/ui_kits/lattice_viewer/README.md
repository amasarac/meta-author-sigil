# Lattice Viewer — UI Kit

Interactive SVG/D3 visualizations of the persona graph.

Source references:
- `animated_spiral_lattice.html` (orbiting glyph nodes)
- `10_10_portal/portal.html` (Triadic Seal, phase rings)
- `convergence_codex/index.html` (Dodecaseal grid)

## Components
- `TriadicSeal` — concentric phase rings + triangle + twin crescents + infinity
- `OrbitLattice` — central glyph with N nodes orbiting
- `NodeTooltip` — hover metrics
- `PhaseLegend` — phase 1/2/3 labels with tick marks
